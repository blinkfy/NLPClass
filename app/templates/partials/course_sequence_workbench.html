HOW IT WORKS

{{ '感知机' if key == 'perceptron' else 'CRF' }}原理

{% if key == 'perceptron' %}

1 · 状态与转移特征

字符窗口、组合及类型描述输入与当前 BMES 标签；相邻标签构成转移特征。

2 · 序列线性打分

将路径上激活的状态与转移特征权重累加，不把得分解释为概率。

3 · 合法路径

复用项目 BMES mask 与 Viterbi，求整句总分最高的序列。

4 · 错误驱动与平均

预测错误时奖励 Gold 路径特征、惩罚预测路径特征；最终使用训练过程中的平均权重。交互预测不更新权重。

{% else %}

1 · 字符状态特征

局部字符窗口映射为各 BMES 标签的状态特征。

2 · 转移特征

学习相邻标签的转移权重，联合给整条路径打分。

3 · 条件概率与训练

CRF 对完整标签序列建立 P(Y|X)，通过全局归一化考虑标签空间，并最大化训练数据的条件似然。

4 · 课程实现

课程以 CRF++ 为工具示例；本项目用 python-crfsuite 实现独立线性链 CRF，训练与整句解码均由库完成。

与感知机的关系

两者共享状态/转移特征和全局序列解码；感知机误差驱动更新，CRF 将同类特征置于条件概率框架。

{% endif %}
