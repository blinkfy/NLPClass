# 实验二第二阶段：文本表示优化对照

本文记录第二阶段固定表示对照；当时未选 winner。第三阶段经用户决定采用 R2 为主表示、K=5 为5主题参考配置，未重拟合任何历史 Run。综合理由与局限见 [exp2_final_summary.md](exp2_final_summary.md)。

本次固定同一 600 篇 THUCNews 全文、文档 ID/顺序、HMM-1 Smooth token 缓存和 KMeans 协议，仅改变表示。R0 只读，不重拟合；R1、R2 各执行一次 K=2…10 × seeds=42/43/44，共 54 次正式 KMeans 拟合。没有搜索表示参数，没有选择唯一 winner，也没有开始实验三。

## 固定协议与数据边界

输入严格为 `ClusteringDocument(id, text)`。先完成两种表示的全部无监督拟合，再打开 gold loader，按唯一 ID 和 text hash 关联冻结的 primary_label。标签只用于外部评价及簇组成；跨 seed stability ARI 比较的是两组聚类分配，不使用 gold。

预处理保持 R0：NFKC、小写、项目已有汉字/英文 token pattern、最短 token 长度 2、不加 stopwords。读取 R0 已验证 hash 的 tokens.jsonl，避免重新分词；分词模型为 `20260926_130612_32a5e168_smooth`。

KMeans：k-means++、n_init=10、max_iter=300、tol=0.0001、Lloyd。每 K 主结果 seed=42；43/44 是相同协议的稳定性重复。表中 silhouette/CH/DB 和外部指标均对应 seed=42；重复保存分配、SSE、迭代次数、簇规模，并计算三对 stability ARI。K=5 为 known-topic reference，不等于无监督选定的最佳 K。

## 技术分析

1. R1 的 DF 过滤达到了减少部分新闻泛化 unigram 的目的，bigram 增加了上下文特征，但空间更稀疏，K=5 silhouette 从 0.018636 降至 0.013424，CH 从 6.425 降至 5.020，DB 从 6.907 升至 7.700，稳定性从 0.834 降至 0.648。仅凭外部 ARI 0.556→0.570 和 NMI 0.685→0.688 的小幅上升，不能宣布 R1 整体更好。

2. R1 最大/最小比例降至 2.775，科技簇扩大至 88 篇，其中 85 篇 gold 科技；混合簇中的科技从 61 降至 30，但体育从 13 增至 40。因此科技/娱乐混合有所缓解的同时，引入了更多体育混合，改善并不一致。

3. R2 压缩并归一化后，K=5 silhouette 为 0.063837、CH 为 18.901、DB 为 3.935，跨 seed ARI 均值为 0.961805（最低 0.942710）。这支持 LSA 空间更清晰、更稳定；外部 ARI 0.593404、NMI 0.720673 也提供事后一致程度提升的证据。教育簇 94 篇全部来自教育，体育簇 112 篇全部来自体育。

4. R2 没有消除主要错误模式：46 篇相机/消费电子子主题占据一个独立科技簇，另有 69 篇科技进入 232 篇混合簇；该簇同时含全部 120 篇娱乐。最大/最小比例 5.043 高于 R0 的 4.854，混合簇规模几乎未变。扎克伯格人物报道仍是混合簇中心代表，说明叙事/媒体词与题材交叉会使 gold 科技与娱乐共享词汇。

5. 最远边界包含短促销、查询/预告、网页说明等文本：安卓平板促销在三种表示中都处于混合簇边缘；R2 体育簇仍以足球为中心，F1 新闻位于远端。边界距离是相对 centroid 的远近，未据此自动宣称数据异常或删除文章。

6. 本次只有一个 Enhanced TF-IDF 配置与一个 LSA 维度，不能拆分 DF/bigram 各自因果贡献，也没有进行维度最优性搜索。100 维仅解释约 29.89% 方差，压缩可能强化主要子主题并丢失尾部信息。结果需要综合内部质量、稳定性、平衡、关键词、gold 事后证据与复杂度讨论；没有人工综合分数，也没有最终 winner。
